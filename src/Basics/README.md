# Java Basics

This folder contains my practice programs for learning the **fundamentals of Core Java**.

The goal of this section is to understand the basic building blocks of Java before moving to topics such as conditions, loops, arrays, methods, OOP, collections, and other advanced concepts.

```text
Welcome to Core Java!
```

**File:** `HelloWorld.java`

# Learning Rules

For every problem, I will follow this process:

```text
1. Read the problem statement
2. Understand the concept
3. Try to solve it myself
4. Write the Java program
5. Run and test the program
6. Check the result
7. Improve the code if necessary
8. Commit the solution to Git
9. Push it to GitHub
```

The main goal is **understanding**, not simply completing as many problems as possible.
